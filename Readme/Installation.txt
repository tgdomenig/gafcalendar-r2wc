Bemerkung:
----------
Der Kalender kann auf zwei Arten gelauncht werden:

(*) wenn index.tsx === index_dev.tsx ist, launche mit npm start. Beachte, dass der Kalender in diesem Fall nicht "gestylt" ist, 
weil die css-Datei erst in Wordpress geladen wird.

(*) wenn index.tsx === index_prod.tsx, so publiziere mit npm run deploy. Diese als github-page publizierte Version wird von der Webseite geladen.

Der Code in Wordpress ist wie folgt:

----------------- Wordpress Code --------------------
<script defer="defer" src="https://tgdomenig.github.io/gafcalendar-r2wc/static/js/main.js"></script>
<body>
  <gaf-calendar-r2wc language="en_US"></gaf-calendar-r2wc>
</body>
----------------- End Wordpress Code --------------------


# https://www.npmjs.com/package/react-to-webcomponent

npx create-react-app gafdbfront --use-npm --template typescript
cd gafdbfront

npm install react-calendar
npm install date-fns
npm install antd

npm install react-to-webcomponent

Bemerkung: Die Datei styles/gaf-calendar-styles.css wird nicht in der Webkomponente verwendet, sondern direkt von WordPress 
(d.h. Datei wird nach wp-content/themes/childtheme/ kopiert)

build (siehe https://www.bitovi.com/blog/how-to-create-a-web-component-with-create-react-app)
-----
add shell script: ./predeploy.sh

npm run build

deploy (siehe https://github.com/gitname/react-gh-pages)
------
npm install gh-pages --save-dev

add to package.json: 
  "homepage": "https://gitname.github.io/react-gh-pages",

add deployment scripts to package.json:
  "scripts": {
    "predeploy": "npm run build",
    "deploy": "gh-pages -d build",
    ...
  }

npm run deploy
